FitLogy

A dark-themed gym companion app where users can browse workouts, add lifts to
today's plan, save workouts for later, and track daily exercise stats.

 Technologies Used
-Next.js (App Router)
-Typescript
-Tailwind CSS
-lucide-react (icons)
-localstorage (persistence)

Features

1. Browse a library of 12 workouts fetched from a live API, with search and sort 
.
2. View detailed workout pages with equipment, difficulty, reps, instructions, and stats.

3. Add workouts to "Today's Plan" (capped at 5) or "Save for Later", with live toast notifications.

4. My Plan page with live-updating metrics  and tabbed Today's Plan / Saved views.

5. Mark workouts as done or remove them from the plan/saved list.

6. Fully responsive design across mobile, tablet, and desktop.

7. Data persists across page reloads using localStorage.

8. Custom 404 page for unknown routes.
